# 截流获客工作台下载与更新

此仓库用于公开发布安装包及更新清单，不公开源码工程仓库及开发记录，不发布账号、Cookie、密钥或数据库。安装包包含运行所需的 JavaScript/Python 程序文件，可以被解包查看。

安装包位于 [Releases](https://github.com/hgod8631-ops/jieliu-workbench-releases/releases)。

Windows 首次从 0.11.1 升级需要先完全退出旧版，运行新版安装包并选择原安装目录。更新器版本安装后可在窗口顶部或托盘检查更新。升级前使用程序自带备份功能导出数据。

安装程序保留原有 data 目录；不要卸载后手动删除目录或将账号资料同步到此仓库。真实设备上的账号登录保持需单独核验。

公开更新入口：[windows-update.json](https://github.com/hgod8631-ops/jieliu-workbench-releases/releases/latest/download/windows-update.json)。安装包发布后才有该文件。

安装包内第三方组件的许可证随程序提供；本仓库不对第三方代码重新授权。
